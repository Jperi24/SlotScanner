## Style Guide

### Writing Style
- Expert but accessible tone
- Use practical examples and analogies
- Include data and statistics where relevant
- Break up long paragraphs
- Use bullet points and tables
- Add warning boxes for important cautions
- Include highlight boxes for key insights

### SEO Best Practices
- Target keyword in H1 and first paragraph
- Use H2/H3 subheadings with keywords
- Include FAQ section for featured snippets
- 2,000-3,000 words per article
- Internal links to casino/slots pages
- Schema.org markup for articles and FAQs
- Meta descriptions 150-160 characters

### Visual Elements
- Emoji icons for sections (🎲 🎰 💰 📊 etc.)
- Color-coded boxes:
  - Yellow/Gold for highlights and tips
  - Red for warnings and cautions
  - Blue for information
- Tables for comparisons
- Consistent styling with main site
